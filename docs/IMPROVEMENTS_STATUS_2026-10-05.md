## 전략 진단과 실제 남은 작업

[전략 진단](../reports/development/strategy-review-2026-10-05.json)은 기존 243세션·71거래의
실제 입력 연구를 사용했다. 전체 +32.42%·MDD -33.93%, 같은 기간 KOSPI +102.66%다.
뒤 81세션은 전략 -28.03%, KOSPI -14.18%로 부진했다. 추가 비용 10/30/50bp를 기존
거래 경로에 적용하면 전체 수익률은 +31.42/+29.43/+27.47%다.
최대 종목 비중 39%, 216세션이 운영 PAPER의 15% 한도를 초과했다.
연구 수익률을 현재 운영 정책의 성과로 사용하지 않는다. 기간 분리는 사후 진단이며
독립적인 최적화·검증 표본이 아니다. 진단 PASS는 전략 승인 PASS가 아니다.

1. KIS 모의투자 키·시크릿·계좌를 비공개 설정에 등록한 뒤 `paper-check` 인증·잔고 PASS를 확인한다.
   현재 세 값이 모두 없어 MISSING_PAPER_CREDENTIALS로 차단됐고 주문은 0건이다.
2. 실제 모의 주문의 부분 체결·재시작·정산을 확인하고 방향별 표본·완료 EOD·장기 세션을 누적한다.
   기존 승격 게이트의 최소 BUY/SELL 각 30건, shadow 10세션, PAPER 60세션 조건은 유지한다.
   7~8월 과거 보고서의 관측 수를 현재 클라우드의 새 증거로 사용하지 않는다.
3. 동일 운영 정책·검증 원천으로 독립 기간의 전략 후보를 평가한다. 최근 손실·MDD·벤치마크
   부진이 해소됐다는 증거 전에는 REAL을 활성화하지 않는다.
4. 클라우드 설정 도구는 초안 저장만 지원한다. 환경 설정 화면에서 불필요한 DART_API_KEY
   바인딩 제거와 최종 저장·게시가 필요하다. 도구로 게시하거나 새 작업 복원을 확인했다고 주장하지 않는다.

원본 재무 결손과 정책 범위 공시의 한계도 남는다. 데이터 생성·8분기 요건 완화·기존 원본 삭제로
이를 숨기지 않았다. 현재 코드는 반복 검증·차단·복구 경로를 제공하며 운영 전체 완료를 뜻하지 않는다.
