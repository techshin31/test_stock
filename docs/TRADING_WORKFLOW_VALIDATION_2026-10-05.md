# 자동매매 연결 검토 및 검증 (2026-10-05)

수집·FA 분석·발행·주문 계획·가상 체결을 연결하는 실행 명령을 추가했다.
KIS 모의투자 연결 준비는 완료했지만, 인증정보가 없어 외부 인증·주문·정산은 검증하지 않았다.
장기간 무인 운영이나 실전 운용 완료를 뜻하지 않는다.

## 수정한 연결 문제

- 기본 DRY_RUN이 KIS 클라이언트를 초기화해 키 없이는 중단되던 문제를 수정했다.
  가상 현금으로 계획만 생성하고 주문 전송을 차단한다.
- DRY_RUN·SIMULATE가 현재 분석기와 다른 FA 버전을 요구하던 문제를 수정했다.
  두 환경도 PAPER와 같은 v1.1을 검증하며 REAL의 기존 모델은 유지한다.
- 전역 FA 후보 파일을 환경별 파일로 분리하고 모델·전략·실행 환경·신호일을 검사한다.
- `apps.system prepare/run`으로 준비도 검사, 분석 PASS 확인, 발행·정합성 감사,
  장전 후보 생성, 거래 시간 내 매매 주기를 연결했다. 휴장·중복 실행·오래된 결과·
  의존성 실패는 명시적으로 차단한다. 자식 프로세스 종료만으로 성공으로 표시하지 않는다.
- `paper-check`는 모의투자 인증·잔고 조회만 수행하며 60초 제한과 비밀값 제외 출력을 적용한다.

합성 입력의 `local-check`도 통과했다. DB 연동 검사는 고유한 임시 DB를 사용했다.

## 남은 운영 조건

- KIS 모의투자 키·시크릿·계좌 등록 후 `paper-check`의 실제 인증 PASS가 필요하다.
  이후 실제 모의 주문·체결·정산 및 장기 운영 관측을 별도로 검증한다.
- 통합 watcher는 EOD 보고서·장기 승격 증거를 대체하지 않는다. 기존 scheduler와 동시에
  실행하지 않는다. 준비 단계의 BLOCKED 동안 보유 포지션 위험관리가 자동 실행되지
  않을 수 있으므로 운영자 확인이 필요하다.
- 원본 재무 12개 항목의 결손·충돌은 계속 제외 사유로 남는다. 8분기 요건을 완화하거나
  데이터를 만들어 채우지 않았다. 전체 금융기관·리츠까지 재무 확보 완료를 주장하지 않는다.
- 이전 실제 FA 백테스트의 +32.42%, MDD -33.93%, 71거래 결과는 별도 연구이며,
  이번 실행 연결 수정으로 수익성이 개선되었다고 해석하지 않는다.
- 클라우드 설정 저장과 게시가 다르다. 현재 제공된 도구는 초안 저장만 지원하므로
  환경 설정의 최종 게시와 불필요한 DART_API_KEY 바인딩 제거는 제품 화면에서 수행해야 한다.
